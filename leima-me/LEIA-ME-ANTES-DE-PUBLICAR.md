# RMF — versão aprimorada

Abra `index.html` ou publique a pasta em hospedagem estática HTTPS.

## Melhorias
- Hero com engrenagem 3D interativa original, órbitas, efeitos e abertura animada.
- Cabeçalho adaptável e identidade visual preservada.
- Texto Sobre Nós centralizado.
- Favicon, metadados sociais, otimização de imagens e acessibilidade básica.
- Formulário com opções reais de preparar e-mail ou WhatsApp.
- Página inicial de privacidade e link no rodapé.

## ATENÇÃO — WhatsApp automático
Um site estático NÃO pode enviar uma mensagem diretamente para o WhatsApp de outra pessoa sem a confirmação do visitante. Para envio automático é necessário um backend autenticado e a API oficial WhatsApp Business Platform, com permissões, templates e requisitos de consentimento aplicáveis. Não coloque tokens de API no JavaScript público. Nesta versão, os dados são preenchidos e o usuário confirma o envio no WhatsApp, ou no seu aplicativo de e-mail. Nenhuma mensagem é falsamente indicada como enviada.

## Antes de publicar
- Confirmar telefone, e-mail, números de obras e alegações comerciais com a RMF.
- Revisar a política de privacidade com o responsável pela empresa.
- Definir domínio oficial para canonical, sitemap e Open Graph URL.
- Testar em aparelhos reais e medir Core Web Vitals.
- Para automação de envio, contratar/configurar backend e WhatsApp Business API com credenciais privadas.
